IMAGES FOLDER

Drop your photos into this folder using these exact file names. Each one lands
in a fixed spot on the site. Until a file is here, that spot shows a dashed
placeholder box, so the site always looks tidy while it is being filled in.

You do not need to edit any code. Just match the file name.

  art1.jpg      portfolio artwork, top left
  art2.jpg      portfolio artwork, top middle

Tips

- The names must match exactly, all lower case, ending in .jpg
- If your photo is a .png, you can either rename it to end in .jpg, or tell me
  and I will switch that slot to .png in the code.
- Good shapes to aim for. The profile photo looks best square, since it is shown
  as a circle. The artwork spots are square. The likes photos are a little wider
  than tall. The site trims each photo neatly to fit, so exact sizes are fine.
- Keep each file under about 2 MB so the site stays quick to load.

Where these images show up per version

- Streamlit version. Images appear automatically. The app reads this folder and
  builds the photos into the page when it runs, so drag and drop just works.
- Google Sites, GitHub Pages route. Keep this images folder next to index.html in
  the repository and the photos load on their own.
- Google Sites, pasted code route. That route cannot reach a local folder, so use
  the GitHub Pages route if you want the photos to show on Google Sites.
